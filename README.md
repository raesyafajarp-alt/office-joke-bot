A program that writes one original one-line joke about office life, entered in make.fun's "One-Line Office Joke Laugh-Off".

## The entry

> I got promoted to Senior — same desk, same pay, just a longer job title for my resignation letter.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (one line, no trailing newline). Running it twice produces byte-identical output.
